# Política de privacidad — Farmacias de guardia (borrador para revisión de Alfonso)

**Responsable:** Alfonso Rivero Muñoz — contacto: alfonsorivero.es@gmail.com.

**Qué datos trata la app**
- **Ubicación del teléfono (GPS):** solo se usa dentro del propio teléfono para calcular qué farmacias
  de guardia están más cerca. No se envía a ningún servidor ni se guarda.
- **Búsqueda de poblaciones:** si el usuario escribe el nombre de una localidad, ese texto se envía al
  geocodificador público CartoCiudad (Instituto Geográfico Nacional) para obtener sus coordenadas.
- **Último lugar elegido a mano:** se guarda solo en el teléfono (preferencias de la app) para usarlo si
  el GPS no está disponible. La posición GPS nunca se guarda. Se borra al desinstalar la app o borrar sus datos.
- **Mapa:** al ver el mapa, el teléfono descarga las teselas de OpenStreetMap; el servidor de teselas
  recibe, como cualquier web, la dirección IP y la zona del mapa que se muestra.
- **Actualización de datos:** la app descarga periódicamente un fichero con los turnos oficiales; esa
  descarga no incluye ningún dato del usuario.

La app no tiene registro de usuarios, ni publicidad, ni analítica, ni identificadores de seguimiento.

**Datos de las farmacias:** proceden de fuentes oficiales con licencia de reutilización (Govern de les
Illes Balears, BORM de la Región de Murcia, Gobierno de Navarra, Ayuntamiento de Madrid y Ayuntamiento
de Zaragoza), citadas en la app.

**Derechos:** como la app no recoge datos personales en servidores propios, no hay datos que consultar,
rectificar ni suprimir. Para cualquier consulta, escribir a la dirección de contacto.
